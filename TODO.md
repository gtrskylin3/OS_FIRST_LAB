Этапы работы

1. Этап 1. Изучение проекта
   Начинаем отсюда
   - Открыть проект.
   - Посмотреть корневой Makefile.
   - Разобраться, какие команды он вызывает.
   - Посмотреть исходники и заголовки, чтобы понять зависимости.

2. Этап 2. Сборка статической библиотеки
   Создать lib/Makefile.
   - Компиляция трёх файлов .c.
   - Получение трёх .o.
   - Создание libcommon.a.
   - Реализация all и clean.

3. Этап 3. Сборка трёх приложений   
   Создать три Makefile.
   - Backend.
   - Balancer.
   - Loadgen.
   Научиться связывать приложения со статической библиотекой.

4. Этап 4. Проверка Make
   - Запустить make.
   - Проверить наличие четырёх результатов сборки.
   - Запустить make clean.
   - Проверить переопределение CC и CFLAGS.
5. Этап 5. Dockerfile
   
   Создать три Dockerfile.
   - Первый этап — сборка.
   - Второй этап — запуск.
   - Разобраться с контекстом Docker и копированием файлов.
6. Этап 6. Docker Compose
   
   Создать compose.yaml.
   - Четыре контейнера.
   - Общая Docker-сеть.
   - Переменные окружения.
   - Зависимости между сервисами.
   - Сохранение CSV на компьютере.
7. Этап 7. Финальное тестирование
   - Запустить всю систему.
   - Проверить чередование ответов Backend.
   - Проверить 1000 запросов.
   - Проверить CSV.
   - Изменить количество запросов на 100 без пересборки образов.
